# Minecraft 26.3 升级指引

## 版本要求

Mili `ver/26.3` 使用 Java 25，基于 Folia 26.3 Build 28。自行构建需要 Git、Java 25 和 Rust；步骤见[贡献指南](CONTRIBUTING.md)。部署时从本仓库 Release 取得 `mili-26.3-paperclip.jar`，不要使用上游 JAR 或普通 CI 构建替代。旧预发布 `26.3-9f255c1`、`26.3-c60a88e` 的启动器不能正确读取补丁，不宜使用。

## 升级与回退

1. 停服备份整个世界目录、插件数据、配置和当前启动 JAR。
2. 用独立目录中的副本试升级。替换启动命令实际引用的**整包**；用过自动更新时，也检查 `auto_update/core.path` 是否指向相同的启动文件。
3. 检查世界成功加载并保存，再停服重启。启用了容器扩容、活塞搬运等改变数据行为的规则时，同时确认对应内容能在重启后读回。验证依赖的插件和客户端能力后，再升级正式服。
4. 回退时同时还原升级前的 JAR、配置和世界。不要让旧版本打开唯一一份新版本存档；新版写入的容器或物品数据尤其不能假定旧版可读。

服务端玩法和需要配套客户端的功能分别列在[兼容速查](carpet-compat-status.md)。自动更新默认关闭，只考虑当前 Minecraft 版本线中可验证的 Mili 正式发行包。
