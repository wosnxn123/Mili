# 26.3 同类补丁同步

**范围：** 直接基线是 Folia Build 28（`b5c78083`）及其指定的 Paper（`827eeeb9`），主要移植来源是同基线的 [Lophine `7a51f49a`](https://github.com/LophineLabs/Lophine/tree/7a51f49a512f1b5465f15a905d3704754e4bed02)。Lophine 的 158 个 Minecraft、27 个 Paper-server、16 个 API 补丁不是 201 个未移植功能；其中有改名、拆分、品牌、不同配置框架和上游已经实现的改动。以下记录实际接入，不以配置项或文件名代替实现。

| 功能线 | 变更 | 默认行为与边界 |
|---|---|---|
| 原版体验 | Lophine 0117 / 0136：旧末地环带、原版体验选项、独立的末影珍珠持久化 | 新增行为默认关闭。环带只影响新生成区块；珍珠在所属区域生成快照，不接管 Paper legacy 模式。原版体验涉及实体挤压、TNT、活塞和怪物计数，并非一键把 Folia 变成原版服务端。 |
| 旧机制扩展 | Lophine 0087–0089、0091/0092、0094、0098：增援僵尸、领袖僵尸生命值、出生保护、袭击/不祥之兆、虚空交易和旧爆炸判定 | 复用 `old-feature` 原有选项。领袖僵尸的 TIS 别名共用同一执行点；出生保护计数器由真人和假玩家共用；袭击效果的读改写遵守实体所属区域。 |
| Carpet、AMS、ORG、TIS | 可再生方块、珊瑚、耕地、末地尖柱、末影人、繁殖冷却、雪层光照、锻造模板等，以及插件只读规则快照 | 逐项见[上游规则审计](upstream-carpet-26.3.md)。不是 Scarpet 脚本运行时整包移植，也不声称与 Lophine 的插件写入/生命周期接口二进制兼容。 |
| 性能补丁 | Lophine 0137–0158 整组：缓存、区块序列化、POI 和矿脉搜索、光照、配方查询等；Mili 原有实现只补差异 | 原作者、来源及逐项对照见 [NOTICE](../licenses/Lophine-0137-0158-NOTICE.txt)。另适配组件映射比较、物品匹配、生物计数、爆炸抗性、包队列及次要 POI 感知。没有新的 TPS 基准结论。 |
| API / Paper-server | 无正则的 `Material.matchMaterial`、复用 Moonrise 区块键、ReferenceList 尾项删除优化 | 延用原 API、同一打包顺序；来源保留在各补丁邮件内。 |
| 去重与基线冲突 | 原 Mili 0071 的 `getVolatile` 已由 Folia 完整实现，不重复打补丁。保留 Folia 的跨维度移除判断、拴绳区域检查、`Locale.ROOT` 数字格式、`minecraft:tp` 及地图自动保存，并保留 Mili 的区域报告和 TIS 采样 | 不能因为本地有旧 Git blob、能三方合并，就认定发布 runner 也能重放；重新导出后在干净环境验证。 |

其他来源也按 **26.2 → 26.3** 检查，而非把各 fork 历史补丁全塞入。检查点为 Leaf `cd863d0c`、Purpur `66b7c921`、Gale 开发线 `89a0e116`。Purpur 的末地环带对应同一玩法，不重复加入第二套生成器。Leaf 的桌面 Swing 控制台主题并不是 Mili 的游戏内配置 GUI；Gale 的 `ClockInstance.rewind()` 是推测执行调度器的配套接口，而非独立可用的原版玩法。核对时 Leaves、Pufferfish 没有公开的对应 26.3 分支，旧 Luminol 地址返回 404。没有将这些来源的旧代码伪装成已验证的 26.3 新版本。

发布前轻量验收：干净重放、Java 25 打包、材料/本轮规则针对性测试、空缓存启动器重建、宿主 JNI/TOML 往返。各目标原生库仍检查是否齐全；跨系统运行矩阵可手动触发。不以旧版本开服或局部 `javac` 代替最终发布包的结果，也不使用生产世界测试。
