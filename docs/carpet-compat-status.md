# Carpet 与客户端兼容

Mili 的玩法配置以服务器生成的 TOML 为准。Carpet 客户端可以读取服务端公开规则，但不会因此获得改规则或执行命令的权限。下表是使用边界，不是完整的客户端联测清单。

| 功能 | 支持与限制 |
|---|---|
| 便携容器 | 可选快捷潜影盒、54 格潜影盒、空盒堆叠及 27/54 格收纳袋菜单。收纳袋扩容使用独立的菜单数据，不修改原版重量条；不保证旧 JAR 能读回新存档。启用前先用副本验证。 |
| 假玩家 | `affects_spawning` 控制参与刷怪；战斗和诱敌只处理本区域目标，不自动攻击玩家或跨区追逐。 |
| 活塞搬运 | 限已加载且由当前区域拥有的箱子、陷阱箱和木桶；双箱需同区块一起移动，不支持任意方块实体。 |
| 下界门与短时加载 | 禁止建门类规则不应阻止使用已有出口。音符盒、钟和活塞可配置短时模拟票，限本世界的固定范围与数量，不是永久加载。 |
| `microTiming` | 默认关闭。管理员可用 `/microtiming watch <pos> [updates]` 暂时观察附近已加载且同区域的方块，`/microtiming read [all\|merged\|unique]` 查看，`/microtiming stop` 停止。这不是 TIS 全局日志或形状渲染。 |
| Carpet HUD | `defaultLoggers` 使用原版 Tab 页脚；`counter` 和 `xcounter` 需查询权限。无需客户端模组，不等于完整 `/log`。 |
| TISCM MSPT | `tiscm:network/v1` 支持已协商客户端的只读**全局** MSPT 样本，默认关闭。不提供测速、区域指标或远程命令。 |
| PCA | 游戏态受限订阅，读取时仍检查可见、距离、当前菜单与权限。不是任意远程 NBT。 |
| Servux 等 Leaves 通道 | 注册或有单向发送不代表双向功能可用。不承诺 Servux 结构订阅、任意 NBT 查询和远程粘贴。替代方块放置是单独的原生交互入口。 |

没有引入 `mergeTNT` 或恢复绊线状态复制。独立 Scarpet 运行时不包含在服务端兼容层内。提供覆盖更多边界的客户端使用说明前，需要用目标客户端和相同服务端 JAR 实测。
