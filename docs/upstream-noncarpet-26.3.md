## 上游接管、现有实现或不重复的历史内容

- **0027 的状态参数**：预览 `ServerLevel#moonrise$loadChunksAsync` 已把 `chunkStatus` 同时传给 `ChunkTaskScheduler.getTicketLevel` 和 `PlatformHooks#scheduleChunkLoad`。只补请求合并，不叠加第二份状态修补、缓存或票系统。0005–0008、0010 已由 0196–0200 接入；0009 的目的地票配对仍以 Folia 为准。
- **区块/传送/命令**：0025 与 hardfork 0027 的实际增删行一致；Mili 0042、0072 已做路径目标区域过滤和跨边界重算或丢弃，0126 优化中点计算。0026 的驯养生物路径已在 0065 用 `getBlockStateIfLoaded`。0020 的长命令、0021 的门传送速度、0022 的骑乘统计及 0023 的创意选物分别已有 0075、0059、0074、0058 的运行路径；不复制第二个命令长度、传送速度或统计写入点。0053 的协议切换与异步 keepalive 有 0026、0121 既有路径；PCA 入站缺失另由 0295 处理。
- **26.3 原版扫描**：`FilteredSectionCache#getOrLoad` 已按 `LevelChunkSection#maybeHas` 跳过不可能的区段。0296 是原生顺序上的额外全窗口空判定和归属门槛，不另建同类区段缓存。
- **配置与公开接口**：0011 在线存储格式、创建工厂与 Moonrise 恢复早在 Mili 0018，不替换格式枚举或配置体系；仅 0297 补离线枚举。0036 的命令方块执行开关和 0048 的定位栏/指令开关都是 hardfork 已有并在 Mili 0019 / 0088 有消费者。Paper-server 0013 的 `MCUtil#toLocation(Level, BlockPos)` 已有 Mili Paper-server 0006；事件无监听者、区块查询 API、区域 Tick API 和传送事件分别有 Mili Paper-server 0009、API 0002/0007、MC 0023。材料、区块键、ReferenceList 早已接入，本轮不需要增 API 或 Paper-server 补丁。
