Validation on the 26.3 patch baseline
-------------------------------------

The affected 33 source files in the default workspace matched the canonical
0125 replay byte for byte. The pinned donor mails matched the donor Git blobs.
The existing 0126/0127 were replayed first. All 20 new mails applied in order
with Git's whitespace checking, and all 31 changed Java files compiled using
javac 25 against cached dependencies. Mail metadata and co-author trailers
matched the donor. No Gradle, full build, or server launch was run.

Focused Java checks passed for piston geometry, no-clip, mismatched bases
and per-thread identity (0139); biome hashes and the Secure Seed constructor
(0140); context validation and diagnostic priority (0144); axis mapping
(0150); heightmap result parity, read counts and uneven tops on a mocked
LevelChunk with fixture predicates (0151); copied/escaped light snapshots
and publication (0155); POI dense/sparse selection, packing boundaries and
visited parity (0156); nested, exceptional, oversized and cross-thread ore
bitmap calls (0157); and recipe call order, runtime priority and empty
input with mock recipes (0158).
Unless listed as a focused check, each new patch was checked by source
review, patch replay and compilation, not by a separate gameplay test.
